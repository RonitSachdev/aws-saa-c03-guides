Assumes you have already read the guides once. Goal: **recall + decision speed**, not new learning.
Daily budget: ~4–5 h (adjust). Method for every topic: **read the Pocket card → cover the answer column → self-test → open the full guide only for rows you miss.**

## Rules for the final 6 days
1. Do **timed practice questions** every day (65 questions / 130 min ≈ 2 min each). Review every wrong answer by asking *which keyword did I miss?*
2. Keep a "**my mistakes**" list; re-read it each morning.
3. Stop studying new material the evening before the exam. Sleep > cramming.
4. Exam technique: read the **last sentence first**, eliminate two, let the qualifier (cost / least overhead / HA / multi-region) decide, flag at 90 s, never leave blanks.
